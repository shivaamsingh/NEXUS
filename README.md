# NEXUS

NEXUS is a next-generation technology intelligence platform designed to discover, analyze, and forecast the evolution of technologies, skills, frameworks, and software ecosystems.

## Vision

Instead of predicting the next token, NEXUS predicts the next state of the technology world.

The system continuously ingests data from:

- GitHub
- Job Boards
- Hugging Face
- Reddit
- Research Papers

and builds an evolving temporal knowledge graph.
